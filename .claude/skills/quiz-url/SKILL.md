# 問題集 URL を作る

`drill.js` が読む query をこちらで組み立てる。UI で1つずつピン留めするのが面倒な、
まとめ生成のためだけの skill。

## 先に読むもの (毎回)

index は `PRONOUNS` / `TENSES` の**並び順そのもの**で、動詞や時制を足すとずれる。
値をここに書き写さず、都度読む。

| 版 | 人称・時制 | 動詞 |
|---|---|---|
| フランス語 (`/`) | `conjugate.js` の `PRONOUNS` / `TENSES` | `verbs.json` |
| ロシア語 (`/ru/`) | `ru/conjugate.js` | `ru/verbs.json` |

動詞名は `infinitiveLabel` を通した文字列。フランス語版で `"pron": true` の動詞は
`se lever` / `s'appeler` のように `se` が付いた形が正しい (母音の前は `s'`)。
`verbs.json` にない綴りを書くと受け手側で捨てられるので、必ず突き合わせる。

## query

ベースは `https://conjugaison-seyes.pages.dev/` (ロシア語版は `/ru/`)。

| param | 意味 | 例 |
|---|---|---|
| `v` | 表に出す動詞 | `v=parler` |
| `p` | **消す**人称の index を1桁ずつ連結 | `p=0235` = tu と nous だけ残す |
| `t` | **消す**時制の index | `t=01234` = 複合過去と大過去だけ残す |
| `op` / `ot` | 並び順。全 index を1桁ずつ。初期順なら省く | `ot=5601234` |
| `x` | 行と列を入れ替え | `x=1` |
| `q` | 出題モード。ピンがあるときだけ効く | `q=1` |
| `pins` | 問題集。1件 `v\|p\|t\|op\|ot\|x` を `,` で連結 | 下記 |

`p` / `t` は**残す**ではなく**消す**index。全部消すことはできず、最後の1本は必ず残る
(受け手が `slice(0, n-1)` で切る)。範囲外と数字以外は黙って捨てられ、`op`/`ot` は
全 index が揃っていないときだけ初期順に戻される。

## pins

1件が `v|p|t|op|ot|x` の6フィールド。空でもパイプは残す。順序は表の出題順。

```
?pins=parler|0235|01234|||,se lever||01234|||1,être|||||
```

- `x` は `1` か空
- 単体の `?v=` と違い `?pins=` で開いた画面は出題モードで始まる (`q=0` を書けば切れる)
- 問題集は URL だけが置き場。ピンの増減は URL に書き戻されるので、保存も共有もリンクを控えるだけ
- 長くなるので、共通の設定は全件に同じ値を書く。省略記法はない

## 作り方

1. 上の2ファイルを読んで index を確定する
2. 対象動詞を `verbs.json` から選ぶ (`kind` / `usage` / `-ir` 語尾などで絞る)
3. 各件を `v|p|t|op|ot|x` に組み、`,` でつないで `?pins=` に入れる
4. 動詞名と index を `verbs.json` / `PRONOUNS` / `TENSES` と突き合わせてから渡す

アプリが「問題集をコピー」で吐く URL は `|` が `%7C`、`,` が `%2C` に符号化されている。
どちらでも受け手は同じに読むので、生のままでも動く。キリル文字やアクセント付きの `v` は符号化しておく。
